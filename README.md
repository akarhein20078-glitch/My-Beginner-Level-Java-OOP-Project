# My Beginner-Level Java OOP Project

## Contact Management System

A beginner-friendly Java project created to practice Object-Oriented Programming (OOP).

## Features
- Add new contacts
- View saved contacts
- Search for contacts
- Update or delete contacts

*Note: Keep only the features that your project actually supports.*

## Technologies
- Java
- IntelliJ IDEA

## OOP Concepts
- Classes and Objects
- Encapsulation
- Constructors
- Methods

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Run the main Java class.
